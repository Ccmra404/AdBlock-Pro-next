## 我们想做的事

网络过滤不该只剩下“开”或“关”。遇到漏拦截、误拦截或网络异常时，用户需要看得见线索、理解影响，并自己决定下一步。

AdBlock Pro 将围绕这个方向持续改进：让本地过滤更可靠，让规则来源和处理过程更容易理解，也让经过确认的经验能够帮助更多人。

## 我们坚持的原则

- **本地优先**：尽量在设备本地完成过滤；涉及外部服务时，由用户选择并确认。
- **用户做主**：建议不替代决定，规则的采用、调整和移除都应由用户掌握。
- **共同完善**：社区经验先核对再共享，让规则持续改进，也保留审查和纠错空间。

我们不以堆叠规则数量或承诺“拦截一切”为目标。更关注的是让每一步都可理解、可选择、可修正。
