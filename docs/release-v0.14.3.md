# AdBlock Pro v0.14.3

## 更新内容

- 修复部分设备开启应用排除后，DNS 接管可能无法启动的问题。
- 改善规则源下载：为 GOODBYEADS 增加备用线路，并允许较大的规则文件在慢速网络下继续下载。
- 增加内置规则线路在线更新。后续线路调整可随规则更新获取，无需每次更新模块；支持 10007、秋风、GOODBYEADS 及共享规则。
- 改进共享规则同步的错误提示，并在镜像返回无法直接使用的压缩内容时尝试其他线路。

## 升级说明

可通过 Root 管理器覆盖安装，安装后重启。现有个人名单、自定义来源、应用过滤选择和其他设置会保留。开启自动规则更新后，模块会在下次更新时获取线路清单；关闭自动更新时，可手动更新规则。

## 验证

组合测试包已在 KernelSU 平板完成安装、重启、DNS 接管、应用排除规则添加与移除、规则更新及在线清单获取验证。规则更新成功加载 13,509 条规则。网络可达性会因运营商、地区和线路而不同。

## 回退

如升级后遇到问题，可覆盖安装上一稳定版 v0.14.2，再正常重启。
