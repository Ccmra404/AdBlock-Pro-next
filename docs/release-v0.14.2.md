# AdBlock Pro v0.14.2

## 更新内容

本次为修复更新，包含 #62、#63。

- 修复 DNS 上游设置中“测试草稿”和“测试并保存”的结果误判：AdGuard Home 自动为地址补充默认端口时，可用 DNS 不再因地址格式不同而被显示为测试失败。
- 同时覆盖普通 IPv4 / IPv6 DNS、DoH、DoT，以及引导和备用 DNS 的测试结果匹配；真实失败或缺少结果时仍会提示失败。测试草稿只读取测试结果，不修改当前 DNS 配置。
- 修复旧版 KsuWebUI 等宿主无法按“酷安”等中文应用名称搜索的问题。宿主缺少名称接口时，通过本机 Android 框架补充名称；应用列表在设备内处理，读取失败或超时时保留包名搜索。

## 升级说明

版本为 `v0.14.2`，versionCode 为 `54`。可直接覆盖安装，完成后正常重启。保留现有账号、规则源、个人名单、AI 配置、DNS 上游、应用过滤选择及其他偏好，无需恢复默认设置。

DNS 测试基于设备当前网络。测试通过只表示该地址完成了测试查询，不保证所有网站都能访问或广告一定消失。如果填写了当前网络不可达的地址，仍需调整后再保存。

## 验证范围

- DNS 结果匹配已通过默认端口、指定端口、IPv4 / IPv6、DoH / DoT、缺失及冲突结果、保存原始输入等自动回归。
- 旧宿主名称补全已在 Android 10、Magisk Alpha、KsuWebUI 1.0 上完成只读辅助查询，成功读取包含中文名称的用户应用；宿主回退、三类 Root 入口、新装及升级保留数据已通过自动回归。
- 本次未新增整包安装、重启及跨网络的真机验收；上述辅助查询不等同于完整升级验收。
- 发布流程在最终主线提交执行项目检查、Go 测试及安全扫描、Android DEX 构建、ARM64 安装包结构、凭据排除和 SHA256 校验。

## 回退

如升级后遇到问题，可覆盖安装上一稳定版 `v0.14.1`，再正常重启。需要保留的数据可先从模块导出；无需通过恢复默认设置进行回退。
