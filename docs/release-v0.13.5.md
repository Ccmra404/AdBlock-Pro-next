# AdBlock Pro v0.13.5

## 更新内容

- 修复主动移除全部规则来源和个人名单后，规则更新被误判失败的问题。
- 修复每日自动更新未下载远程订阅的问题。更新仅处理已启用来源，失败后间隔重试，核心停止或模块禁用时不会自动重启。
- 修复用户修改订阅链接后又被迁移逻辑改回的问题，并保留来源移除状态。
- 个人域名在拦截与放行名单之间切换时，移除另一份名单中的同名条目；导入存在冲突时整批拒绝，避免部分写入。
- 区分观察结果读取失败和真正的零域名结果，改善接管关闭时的提示。
- 重新打开 WebUI 后，继续跟踪“恢复默认设置”的后台任务。
- 含账号和 AI 密钥的完整恢复备份仅保存在 Root 私有目录；`Download/AdBlock Pro` 只导出个人名单及基础偏好。
- 修正本地管理 API 的 GET 超时参数，并补齐 Go 组件许可证声明。

## 升级说明

版本为 `v0.13.5`，versionCode 为 `51`。普通覆盖升级保留账号、订阅、个人名单和现有偏好，无需恢复默认设置。AdGuard Home 核心和随包默认规则不变，IPv6 DNS 接管仍默认关闭。

## 验证范围

本版本功能代码与已验证的 `v0.13.4-dev.5436929` 测试包一致，版本准备仅调整版本信息和更新日志。

- KernelSU 系设备：覆盖安装、一次正常冷启动、IPv4 DNS 接管、总览及名单页、内存采集、个人名单即时应用和后台域名观察通过。
- 原账号、个人名单和启动偏好保留；测试观察完成后恢复原查询日志设置并释放任务锁。
- 恢复默认设置的备份与脱敏通过隔离测试，未在本轮清空真实用户数据。
- Magisk、APatch、网络切换、真实 AI 调用和完整 24 小时自动更新周期尚未补测。上游核心安全扫描可达性继续跟踪 Issue #24。

相关修复：#32～#40。版本 PR 的自动化和 ARM64 构建结果以对应提交的 GitHub Actions 为准。
