# AdBlock Pro v0.14.5

## 更新内容

- 统一模块个人数据目录，保留旧路径兼容入口；安装、状态迁移、恢复默认设置、卸载和空间统计使用新的布局。
- 改进 BusyBox 目录创建兼容，减少部分环境因目录创建异常而中止安装或后台任务的情况。
- 优化大名单导入、观察结果、应用过滤搜索和个人规则生成，减少重复扫描与进程开销。

## 升级说明

通过 Root 管理器覆盖安装并重启，已有个人名单、订阅和配置会保留。

降级到 v0.14.4 或更早版本前，先在当前版本的 Root 终端执行：

`/data/adb/adblockpro/bin/adblock-bootstrap prepare-downgrade`

确认成功后再安装旧版本并重启。

## 验证范围

- Xiaomi Pad 8 Pro、Android 17、KernelSU 系列：目录迁移、重启后 DNS 核心与 IPv4 接管、名单管理及卸载恢复已实机验证。
- 大名单界面、应用排除校验和个人规则生成的组合候选包已安装并重启，DNS 核心、TCP/UDP 监听及 IPv4 接管正常。实际设备个人名单为空，超大名单性能只由本机回归覆盖。
- 目录创建异常在 WSL BusyBox 中注入 `EINVAL` 复现并通过回归测试；用户反馈的原始安装失败未能在设备上复现，因此不能把它等同为已确认根因。
- 正式发布工作流会在发布的主线提交上重新构建 ARM64 安装包，并执行项目检查、包结构、凭据排除与 SHA256 校验。

## 回退

普通问题可覆盖安装上一稳定版并重启。由于本版迁移了个人数据目录，降级前请按上面的步骤准备旧版兼容布局。
