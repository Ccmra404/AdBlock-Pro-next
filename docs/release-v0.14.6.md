# AdBlock Pro v0.14.6

## 更新内容

- 修复部分设备在设置应用过滤后重新开启 DNS 接管时，应用列表查询失败的问题。
- 改进 Android Shell 对较大数值和时间的兼容，减少启动等待、任务状态及规则同步受到整数范围限制的影响。
- 限制模块历史日志的占用，保留近期记录，减少长期使用时的存储增长。
- 更新项目主页和 AdGuard Home 版本说明。

## 升级说明

通过 Root 管理器覆盖安装并重启，原有名单、订阅和配置会保留。

如需降级至 v0.14.4 或更早版本，先在当前版本的 Root 终端执行：

`/data/adb/adblockpro/bin/adblock-bootstrap prepare-downgrade`

确认成功后再安装旧版本并重启。

## 验证范围

- 本版合入的代码已分别经过对应 PR 的自动化检查；最终发布版本仍需以发布提交的检查和设备验收结果为准。
- 应用过滤、DNS 接管开关、重启后的网络状态和规则管理需在真实设备上验证。不同 Root 管理器的兼容情况应分别确认。

## 回退

如遇异常，可先关闭模块 DNS 接管以恢复系统解析，再按升级说明准备兼容数据，覆盖安装上一稳定版并重启。
