# AdBlock Pro v0.13.4

## 更新内容

- 新增“恢复默认设置”，将模块设置、规则订阅、个人名单和 AdGuard Home 配置恢复为当前安装包默认状态。执行前会自动备份到 `Download/AdBlock Pro`。
- 个人规则、共享规则、域名观察结果和操作日志的导出文件统一保存到 `Download/AdBlock Pro`。
- 修复备份压缩包把自身重复打入的问题，并限制备份文件权限，避免凭据被其他应用读取。

## 升级与兼容

普通覆盖升级会保留现有设置和用户数据。只有主动使用“恢复默认设置”才会重置配置；操作前请确认备份已生成。版本为 `v0.13.4`，versionCode 为 `50`。IPv6 DNS 接管仍默认关闭。

## 验证范围

- 自动化：代码检查、Shell/Node/Python/Go 检查及 ARM64 安装包构建通过。
- 实机：维护者确认小米平板 8 Pro 实测通过，包括恢复默认设置和 Download 导出目录。
- 尚未单独完成 KernelSU 与 APatch 的本次恢复默认设置专项实测；Magisk/其他 Root 管理器验证不替代这些设备验证。
