# 共享应用广告规则与本机名单

模块基础规则包含 10007、秋风 AdGuard 全规则及维护者确认的共享应用广告域名。共享规则随安装包预置，首次安装和覆盖升级均可离线加载；不会把它们追加到本机黑白名单。

在「个人规则 → 共享抓包规则库」查看、搜索或分页浏览已审核的共享域名。点击「同步并应用」读取本公开仓库的快照，校验后应用到 AdGuard Home；失败时保留上一份有效文件。本机白名单可放行共享库命中的域名。共享库不提供重复导出，候选提交也不会直接改动已发布名单。

共享规则是维护者确认后的公共名单，不会自动上传手机观察结果。代码审查期间的测试包固定同步该提交的快照；合并后的包使用 `main` 快照。「同步并应用」会更新公共快照，共享来源启用时才加载到核心。手动规则更新和模块每日自动更新也会尝试同步已启用的共享来源；移除来源后不会把它强制重新加入。

## 本机个人名单

个人黑白名单与共享库、原生后台 `user_rules` 分开管理。导入前会校验格式并预览新增数，跳过重复及与现有相反名单重叠的项，用户确认后合并。后端会重新检查当前名单；若存在冲突或无效域名，整批拒绝，不部分写入。支持不超过 64 KB、5,000 条的 TXT 或 JSON。导入和手动编辑后自动单独应用个人名单，无需下载全部订阅或重启 DNS；应用失败时可点「应用个人名单」重试。手动将域名改为拦截或放行，会移除相反名单中的同名条目，保留其他域名。

TXT 可使用模块导出的格式：

```text
[拦截名单]
ads.example.com

[放行名单]
login.example.com
```

也支持单列拦截域名及完整域名规则 `||ads.example.com^`、`@@||login.example.com^`。不接受任意 Adblock 脚本、URL 或正则。

JSON 格式：

```json
{"format":"adblock-pro-personal-rules","version":1,"blacklist":["ads.example.com"],"whitelist":["login.example.com"]}
```

Root WebUI 导出文件保存到 `Download/AdBlock Pro`。导入内容不会写入操作日志，也不会发送到 GitHub。

## 短时应用观察

在「名单」页顶部输入本机应用名称或包名，选择匹配项。默认观察 10 秒，可选 5、15、30 秒。开始后重新打开选定应用；不清除应用数据。旧版宿主缺少应用名称接口时，使用包名匹配。

安装或删除应用后，返回已打开的名单页会重新读取应用列表；也可点「刷新应用」立即更新。刷新保留当前搜索内容并重新匹配，不需要重启设备。

观察结果默认收起，点击「观察结果」展开候选域名。可以按页多选、复制纯域名、导出 TXT，或复制给 AI 分析的模板；只处理用户勾选的域名，不带应用名称、设备标识或完整查询日志。也可以确认后把所选域名合并进本机个人拦截名单，现有黑白名单优先并会跳过重复项。需要向共享库贡献时，前往「共享抓包规则库」点击「提交候选」。运行日志页只保留观察操作记录。

可以复制候选给外部 AI 辅助判断，再按上述 TXT 格式从「名单」页导入；也可配置[可选 AI 接口](ai-domain-analysis.md)，确认后仅发送勾选域名。AI 输出仍需核对，不会自动修改名单或提交共享规则。

观察临时开启本机 DNS 查询日志，并在完成或启动失败时恢复原设置。期间可能混入后台应用请求，不能据此认定某域名属于所选应用或必定是广告。候选域名仍须人工确认。观察本身不会上传结果；可选 AI 分析需要另外确认发送。

### 社区贡献

在域名观察结果中勾选要贡献的域名，然后从共享规则库点击「提交候选」。模块只复制一个预填 GitHub Issue 草稿链接，其中仅含所选域名及隐私确认提示，不包含应用名称、设备标识或 DNS 查询日志。用户打开链接后仍需检查内容并手动提交；维护者会验证域名、查重、评估误拦截和必要服务影响，再决定是否更新共享规则快照。未审核的候选不会进入模块规则，也不会自动同步给其他设备。
