# 共享应用广告规则与本机名单

模块基础规则包含 10007、秋风纯广告及维护者确认的共享应用广告域名。共享规则随安装包预置，首次安装和覆盖升级均可离线加载；不会把它们追加到本机黑白名单。

在「个人规则 → 共享抓包规则库」查看、搜索、分页或导出共享域名。点击「同步并应用」读取本公开仓库的快照，校验后应用到 AdGuard Home；失败时保留上一份有效文件。本机白名单可放行共享库命中的域名。

共享规则是维护者确认后的公共名单，不会自动上传手机观察结果。代码审查期间的测试包固定同步该提交的快照；合并后的包使用 `main` 快照。共享同步目前由按钮或手动规则更新触发；AdGuard Home 的每日订阅更新不会自动下载 GitHub 共享快照。

## 本机个人名单

个人黑白名单与共享库、原生后台 `user_rules` 分开管理。导入将新域名合并、去重并保留原名单；导入和手动编辑后，执行规则更新才会应用。支持不超过 64 KB、5,000 条的 TXT 或 JSON。

TXT 可使用模块导出的格式：

```text
[拦截名单]
ads.example.com

[放行名单]
login.example.com
```

也支持单列拦截域名及完整域名规则 `||ads.example.com^`、`@@||login.example.com^`。不接受任意 Adblock 脚本、URL 或正则。

JSON 格式：

```json
{"format":"adblock-pro-personal-rules","version":1,"blacklist":["ads.example.com"],"whitelist":["login.example.com"]}
```

Root WebUI 导出文件保存到手机 Download 目录。导入内容不会写入操作日志，也不会发送到 GitHub。

## 短时应用观察

在「名单」页顶部输入本机应用名称或包名，选择匹配项。默认观察 10 秒，可选 5、15、30 秒。开始后重新打开选定应用；不清除应用数据。旧版宿主缺少应用名称接口时，使用包名匹配。

观察结果默认收起，点击「观察结果」展开候选域名，可确认加入拦截或放行名单。运行日志页只保留观察操作记录。

观察临时开启本机 DNS 查询日志，并在完成或启动失败时恢复原设置。期间可能混入后台应用请求，不能据此认定某域名属于所选应用或必定是广告。候选域名仍须人工确认；结果不上传，不使用 AI 接口。

GKD 项目入口改为复制官方链接，避免 Root WebUI 内导航造成卡顿。GKD 仍独立安装和管理。
