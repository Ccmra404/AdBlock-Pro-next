# AdBlock Pro v0.14.0

## 更新内容

- 新增可选的 VPN/TUN 自动兼容模式。检测到常见 TUN/WireGuard 接口时暂停模块 DNS 重定向，AdGuard Home 核心保持运行；接口稳定消失后按原接管偏好恢复。默认关闭，不改写代理软件配置。
- 新增上游 DNS 管理、国内预设与连通性测试/恢复入口，便于按当前网络排查解析问题。
- 新增网络诊断信息，可查看 IPv6、私人 DNS 与 VPN 的实际状态；域名检查结果补充中文说明和误拦截放行入口。
- 新增可选 GOODBYEADS 来源及配套放行规则；共享抓包规则库接纳经审核的社区贡献。
- 改进 DNS 核心异常退出后的有限恢复，并在防火墙状态未知时保留 fail-open 保护。
- 收紧 DNS 核心工作目录权限，更新 Go 组件安全补丁及安装包校验。

## 升级说明

版本为 `v0.14.0`，versionCode 为 `52`。可直接覆盖安装，保留账号、个人名单、订阅来源、上游配置和其他用户偏好。新增 VPN/TUN 自动兼容模式默认关闭；启用后会在检测到常见隧道接口时暂停 DNS 重定向，并在接口稳定消失后按原设置恢复。不同 VPN 客户端和网络配置表现可能不同，建议先在自己的设备上确认。IPv6 DNS 接管默认仍关闭。

## 验证范围

- Redmi K90 Pro Max、Android 17、KernelSU、FlClash：已对本版本相同的运行时代码完成 VPN/TUN 连接与断开测试。连接时 DNS 重定向暂停且 AdGuard Home 保持运行；断开后约 15 秒恢复。手机当前配置已恢复为兼容模式关闭、DNS 接管关闭。
- 新版本准备只修改 `module.prop` 的版本号和本更新日志；正式包将在最新主线 SHA 上由 ARM64 发布工作流重新构建，并通过结构、校验和、架构及凭据排除检查。
- 其他合入功能的回归以本次主线 Actions 单元、Shell、Go、规则和 ARM64 打包检查为准；Magisk 与 APatch 设备未在本次发布前单独实机验证。

## 回退

如升级后遇到问题，可在 Root 管理器中覆盖安装上一稳定版 `v0.13.5`，再正常重启。安装前保留个人配置和规则备份；不要使用“恢复默认设置”作为降级步骤。
