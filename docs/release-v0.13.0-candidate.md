# v0.13.0 候选版验收记录

目标版本为 `v0.13.0 / versionCode 46`。本次仅准备版本信息和验收记录，依赖尚未合并的 [PR #8](https://github.com/Ccmra404/AdBlock-Pro-next/pull/8)。开发分支安装包保留 `-dev.<sha>` 标记；候选包不等于已发布的稳定版。

## 包含的改动

- 域名观察结果支持选择、复制、TXT 导出和分析提示词复制，不接入 AI API。
- 经用户确认的域名可导入个人规则；共享规则库提供候选提交入口，生成 GitHub Issue 草稿，需用户自行审阅和提交。
- 本机应用目录支持刷新，新安装应用可以重新匹配；已有搜索和名单在读取失败时保留。
- 保留 AdGuard Home DNS 架构、KernelSU/Magisk/APatch 兼容层、IPv4 接管及默认关闭的 IPv6 接管。

## 已有验收证据

- PR #8 的 WebUI 回归、Python 测试、Shell/Go 检查及 GitHub 原生 ARM64 构建已通过；新候选提交仍需重新运行相同 CI。
- 小米 Pad 8 Pro（KernelSU/ReSukiSu）已验证前一功能包的安装重启、本机应用匹配、自动打开应用和观察结果展示。普通 DNS 查询能进入观察结果，正常结束后临时查询日志关闭。
- 用户已将 QQ 音乐场景认定为通过，并要求结束该应用的广告排查。这不代表 DNS 能删除所有开屏广告，缓存广告及绕过系统 DNS 的请求仍可能出现。

## 发布前仍需确认

- 曾出现设定为 10 秒的观察任务延迟收尾，原因尚未查明；本版本准备不包含对此问题的修复，不能将其描述为已解决。
- 最新候选包的覆盖安装验收，以及新增复制、文件导出、导入和共享草稿在 Android 宿主中的完整操作验收。
- 新增观察工作流的 Magisk/APatch 真机兼容性，以及 Wi-Fi/移动网络切换场景；CI 和旧版本验收不能替代这些结果。
- PR #8 和版本准备分支经过审查后进入同一主线，并对将要发布的确切 SHA 构建验证。

本次不合并主线、不创建 Release、不改变用户配置、凭据或规则，不操作设备重启。正式发布应走已授权的主分支手动流程，不覆盖既有 tag 或资产。
